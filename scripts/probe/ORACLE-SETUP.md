# الخادم المجاني: ما تفعله أنت، وما أفعله أنا

عشر دقائق منك، والباقي عليّ. لا تُنشئ شيئاً غير الوارد هنا.

## لماذا لا أفعلها أنا

إنشاء حساب Oracle يتطلّب كلمة مرور وبطاقة للتحقّق من الهوية. لا أُدخل
كلمات مرور ولا أرقام بطاقات، ولا أُنشئ حسابات. هذا حدّ ثابت لا استثناء فيه.
كل ما بعد إنشاء الحساب أستطيع تشغيله وحدي.

## ١. الحساب

<https://www.oracle.com/cloud/free/> ثم **Start for free**.

**المنطقة الأساسية تُختار مرّة واحدة ولا تتغيّر بعدها أبداً، وموارد
Always Free لا توجد إلا فيها.** اختيارها خطأ يعني حساباً لا ينفع لهذا
الاختبار، وإصلاحه حساب جديد.

اختر المنطقة السعودية المعروضة عليك في القائمة. **جدّة والرياض سواء تماماً
لهذا القياس**، والذي يُقاس هو «داخل السعودية»، لا المدينة. فإن لم تُعرض
جدّة فخذ الرياض ولا تتوقّف.

البطاقة للتحقّق فقط، ويُحجز عليها مبلغ رمزي ثم يُردّ. احرص أن يبقى الحساب
على **Always Free** ولا ترفعه إلى مدفوع.

## ٢. المفتاح

نفّذه هنا على اللابتوب، وسيولّد زوج مفاتيح لهذا الغرض وحده:

```bash
ssh-keygen -t ed25519 -f "$USERPROFILE/.ssh/rasid-oracle" -N ""
```

## ٣. الآلة

من لوحة Oracle: **Compute ← Instances ← Create instance**

| الحقل | القيمة |
|---|---|
| Image | Canonical Ubuntu 24.04 |
| Shape | `VM.Standard.E2.1.Micro` (عليها وسم Always Free) |
| Networking | Assign a public IPv4 address = نعم |
| SSH keys | الصق محتوى `.ssh/rasid-oracle.pub` |

إن ردّت **Out of host capacity** فذلك شحّ في نوع الآلة لا رفض للحساب: جرّب
نطاق توفّر آخر ‎(Availability Domain) أو أعد المحاولة لاحقاً. لا تنتقل إلى
شكل مدفوع.

## ٤. ما أحتاجه منك

سطر واحد: **العنوان العام للآلة** ‎(Public IP).

المفتاح الخاص يبقى على جهازك ولا يخرج منه، وأستعمله من هنا عبر `ssh`.

## ٥. ما أفعله بعده

1. أفتح الاتصال وأثبّت Node.
2. أنقل `vantage-probe.mjs` و`targets.json`.
3. أشغّل `--vantage=oracle-jeddah` وأُنزل النتيجة.
4. أضع النتيجتين جنباً إلى جنب، مضيفاً مضيفاً، وأطبع رمز الخروج.
5. إن نجح، أوسّع القياس إلى الـ٩٤ مضيف ‎.gov.sa كلّها قبل أي قرار معماري.

عشرة مضيفين يحسمون الاتجاه، والأربعة والتسعون تحسم الكلفة.
